# Zakuwanie Markowa

Strona lokalnego serwisu **zakuwania węży hydraulicznych** w Markowej (okolice Łańcuta).

**Live:** [zakuwanie-markowa.vercel.app](https://zakuwanie-markowa.vercel.app)

## Stack

- Next.js + React + TypeScript
- Leaflet / react-leaflet (mapa dojazdu)
- optymalizacja galerii obrazów (skrypty Node)
- Deploy: Vercel

## Funkcje

- oferta i parametry zakuwarki
- galeria realizacji
- FAQ SEO pod lokalne wyszukiwania
- formularz kontaktowy
- mapa lokalizacji serwisu

## Start lokalnie

```bash
npm install
npm run dev
```

Otwórz [http://localhost:3000](http://localhost:3000).
